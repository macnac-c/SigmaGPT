# 🤖 SigmaGPT

A full-stack AI chatbot application inspired by modern conversational AI platforms, where users can interact with an AI assistant, manage conversation threads, and receive formatted responses with Markdown and code syntax highlighting.

## 🚀 Live Demo

**Live Website:** 

**Frontend:** https://sigmagpt-frontend-qnyz.onrender.com

**Backend:** https://sigmagpt-backend-39xj.onrender.com

**GitHub Repository:** https://github.com/macnac-c/SigmaGPT

---

## ✨ Features

* AI-Powered Conversational Chat
* OpenAI API Integration
* Create and Manage Conversation Threads
* Retrieve and Delete Conversation Threads
* RESTful API Architecture
* Markdown Rendering for AI Responses
* Code Syntax Highlighting
* Responsive Chat Interface
* MongoDB Database Integration
* Conversation History Management
